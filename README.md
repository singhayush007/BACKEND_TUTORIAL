# 🚀 Backend Tutorial  

This repository contains my personal practice and learning projects for **Node.js**, **Express**, and **MongoDB**.

---

## 🧠 What I’m Learning  

### ⚙️ Core Backend Concepts  
- Understanding **Node.js Runtime** and **Event Loop**  
- Difference between **Synchronous** and **Asynchronous** programming  
- Working with **Promises**, **async/await**, and **callbacks**  
- Handling **modules** and **package.json**  
- Understanding **require** vs **import/export**  

### 🧩 Express.js Fundamentals  
- Setting up a basic **Express server**  
- Working with **Middleware** (`app.use()`, `express.json()`)  
- Implementing **Routing** (`GET`, `POST`, `PUT`, `DELETE`)  
- Handling **Params** and **Query Params**  
- Sending **JSON responses** using `res.json()`  
- Using **res.set()**, **res.status()**, and **res.send()**  
- Working with **Error Handling Middleware**  

### 🔐 Security & Middleware  
- Using **CORS (Cross-Origin Resource Sharing)**  
- Creating **Custom Middleware** for authentication and logging  
- Setting and removing **Headers** in Express  
- Understanding **Proxy** and its relation with CORS  
- Environment variables using **dotenv**  

### 🧰 Database (MongoDB)  
- Setting up **MongoDB Atlas** connection  
- Performing **CRUD operations**  
- Using **Mongoose** for schema and model creation  
- Understanding **Schema Validation**  
- Querying and filtering data efficiently  

### 🧠 Advanced Topics  
- **Async/Await** with Database operations  
- Creating **RESTful APIs**  
- Structuring large Express projects  
- Connecting frontend with backend via **API calls**  
- Handling **Middleware Flow** (request → response → next)
